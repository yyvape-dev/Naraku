# ラナ「天地開闢」V2 試作・Claude引き継ぎ（2026-10-11）

## 採用判断
試作。ユーザーによる実機評価待ち。本番コードは変更禁止。テストURLは /lana-v2.html 。

## 目的
旧版は全画面画像のクロスフェード・拡大が「貼り付けた絵」に見えた。各着弾点で現象が起こり、床・空中が独立するよう再構成。

## 実装場所
本番ソース `dev/naraku_src.html` の `drawLanaUlt(g,layer)` と `ultLanaCol(x,hw,pal)` を試作側でランタイム置換している。参照: `lana-v2.js`。
本番の `index.html` は改変していない。

## 描画設計
- `FX.lanaU.t`：演出時計。時間起点はカットイン終了後。既存の更新関数を維持。
- 6地点：`x=30+i*60` (i=0..5)、`y=B.lineY*.5`。開始 `t=.04+i*.06`。
- `layer='floor'`：地面の楕円形の暗い凹み＋枝状の赤黒い亀裂。0.25秒で伸長、1.75秒で発光終了、4.25秒で完全消失。敵・味方の下。
- `layer='top'`：各地点に縦方向のグラデ光柱。開始 `t=.08+i*.06`、0.20秒で伸長し1.55秒以内に消失。各柱に8粒の岩片＋全域35個の弱い火の粉。敵・味方の上。
- `layer='aura'`：従来のラナオーラ画像4枚を利用。1.6秒まで表示、2.1秒で消失。味方描画の直前。
- ピーク：`t=.56` 周辺の0.22秒間、弱い帯状閃光。
- 乱数：描画の再現性を保つため座標は `sin(seed)` ベースの固定擬似乱数。戦闘用シードは触らない。
- `ultLanaCol` は破片と軽い振動のみ。命中・範囲・攻撃力・カード定義・セーブを変更しない。

## 移植方法
1. `lana-v2.js` の `const replacement=function drawLanaUlt(g,layer){...};` 内の関数を、`dev/naraku_src.html` の同名関数へ移植する。
2. 同ファイルの `ultLanaCol` を置き換える。試作の `w.eval(...)` と iframe 部分は本番に不要。
3. 過去の `LANA_U.f/t` と全面素材はV2の床・上空で使わない。残すなら削除前に他参照を確認。
4. `drawZone` の sword に対する `vtex('lanaU_f4')` 条件は旧全面素材の抑制ロジック。V2移植時も従来ゾーンが二重表示にならないよう挙動確認。
5. `tests/smoke.py`、`tools/dev/boot.py` 実施。6着弾・敵重なり・画面幅375/390で目視比較。戦闘結果とRNGが同じことを検証。
6. ユーザーの本採用指示があるまで本番には反映しない。
